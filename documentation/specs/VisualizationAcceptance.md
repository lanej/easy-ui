# Visualization improvement acceptance

This checklist covers the complete September 20 improvement plan on the existing combined Lane J PR. The [combined PR](https://github.com/lanej/easy-ui/pull/1) records the verified source revision, browser/layout runs, and rendered artifacts. The original source anchors and reproduced symptoms remain in the workspace review register. Assess acceptance against those recorded runs as well as the implementation and regression cases below.

## Behavior and API findings

Chart's built-in data disclosure supports rich cell renderers, column alignment and widths, and a configurable scroll height. It remains folded by default. Custom content mounts on first opening, retains local state across collapse, and receives original values/row IDs; null/undefined render results preserve plain/missing-value fallbacks. `ChartDataView.test.tsx` covers this lifecycle and keyboard row selection; `preview-metrics/audit/chart-data-view-checks.mjs` covers the actual chart disclosure, comparison badges, large text, and keyboard table scrolling across browser workflows.

The same disclosure retains column headings during vertical scrolling and optionally pins leading identifying columns. Pinning measures actual widths, follows inline direction, and releases columns to leave at least half the viewport for data. Optional per-column sorting uses raw/supplied values, keeps missing values last, preserves stable row/cell identity, and supports controlled null and restoring application order. Unit coverage exercises sorting, record refreshes and retained cell state; browser coverage checks keyboard sort, sticky geometry, complete row identity, large text, narrow layouts and RTL.

Typography roles are CSS-pixel title/description/label/control/legend/detail values. Defaults are 18/14/12/14/12/12, with explicit engine options taking precedence. Native components expose relevant roles; textless Sparkline marks instead retain screen-space dimensions. Font changes must propagate through DOM/engine styles and measurement. The 12px annotation / 14px prose floor is the declared example-review contract, not a general accessibility certification.

## Performance evidence

A focused 1,000-row, six-column grouped-grid profile with ten collapsed groups recorded 6,000 expensive cell-renderer calls before the change and zero afterward. An illustrative single local sample decreased from 185ms to 91ms; this is not a general benchmark or performance guarantee. Selection/select-all tests include hidden selectable rows and exclude disabled rows. The map test uses 500 facilities and five selection/visibility updates, requires zero unchanged-source uploads, then requires the changed source to update when the data changes.

## Delivery-cell inspection

- Pointer hover exposes supplied summary/distribution data near the cell; pointer movement into the card preserves it. Click/tap pins it; Close, Escape, and outside input dismiss it. Cards stay inside narrow/large-text viewports with space for attribution.
- Supplied quartiles and endpoints are rendered by the native RangePlot. Median/IQR alone produce a summary, never inferred quartiles or a fabricated histogram. Invalid distributions do not produce marks; true zero and equal endpoints remain representable.
- Callbacks/custom renderers receive the original application record. Geographic identity preserves refreshed pinned data across array reordering. Hidden layers, removed/unsupported cells and map reloads clear stale cards. Missing IQR stays unfilled and noninteractive when the spread metric is active.
- Exact-data row disclosures expose the same chart with keyboard access, including after an engine failure. Custom chart content mounts only while expanded. The default detail component is independently reusable; applications can hide the map card while keeping callbacks and exact data.

Evidence: component tests in `NetworkMap.test.tsx` and `NetworkMapCellDetails.test.tsx`, real MapLibre expression evaluation in `surfaceRendering.test.ts`, and Chrome/Firefox/Safari `scripts/preview-maps/inspection-checks.mjs`.
