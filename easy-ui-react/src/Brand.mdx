EasyPost symbol with the “Easy UI” name in the shared Poppins typeface.

## Small sizes

Use the official symbol where the product lockup will not fit. Keep its
proportions and leave clear space around it at small sizes.

<div
  className="sb-unstyled"
  data-easy-ui-brand="sizes"
  style={{
    display: "flex",
    alignItems: "end",
    flexWrap: "wrap",
    gap: 32,
    color: "var(--ezui-color-primary-500)",
  }}
>
  {[16, 24, 32, 64].map((size) => (
    <div
      key={size}
      style={{ display: "grid", justifyItems: "center", gap: 12 }}
    >
      <EasyUIIcon
        width={size}
        height={size}
        aria-hidden="true"
        focusable="false"
      />
      <span style={{ color: "var(--ezui-color-neutral-900)", fontSize: 14 }}>
        {size}px
      </span>
    </div>
  ))}
</div>

## Use in a component

Pass the symbol to the existing [`Icon`](/docs/primitives-icon--docs) component.
It inherits size and color tokens, including the active light or dark theme.
Supply a label when the mark conveys meaning on its own; omit it beside visible
“Easy UI” text.

<Canvas of={BrandStories.Mark} />

```tsx
import { Icon } from "@easypost/easy-ui/Icon";
import EasyUIIcon from "@easypost/easy-ui-icons/EasyUI";

<Icon
  symbol={EasyUIIcon}
  color="primary.500"
  size="lg"
  accessibilityLabel="Easy UI"
/>;
```
