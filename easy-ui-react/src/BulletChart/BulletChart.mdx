# BulletChart

A compact measure against a target: a filled bar, target marker, and explicit zero-based scale. Native HTML/CSS; no chart engine. Import from `@easypost/easy-ui/BulletChart`.

<Canvas of={Stories.Default} />
<Canvas of={Stories.CostTarget} />

Supply a finite positive `max` and non-negative `value` and `target`. Set the same `max` to compare multiple measures in the same unit. Null shows `emptyLabel`; invalid values show `invalidValueLabel`. Finite values beyond the scale retain their exact value with `outOfDomainLabel` and omit their mark by default. Choose `overflow="clamp"` to draw them explicitly at the boundary while retaining the exact value and outside-scale label. Invalid scales show `invalidScaleLabel` and no marks; zero remains observed data. A missing measure suppresses the plot while preserving the target as text.

For a present invalid or outside-scale measure, the supplied scale and any valid target remain visible. Omitting one mark does not remove the other mark or the shared scale.

<Canvas of={Stories.Overflow} />

`formatValue` controls exact values and accessible descriptions. Use `formatAxisValue` for shorter scale endpoints, without losing precision elsewhere. `typography` configures text sizes by role.

<Canvas of={Stories.NoData} />
<Canvas of={Stories.Zero} />

Exact measure, target, and scale remain available without hover. The target uses a marker shape instead of color alone. No animation or keyboard interaction. Exceeding a target does not automatically imply success: the application owns business meaning, metric definitions, units, and loading/error states.

This intentionally small component has one measure and one target. Use `Chart` for qualitative range bands, signed values, multiple series, tooltips, or a full analytical view.
