# CodeSnippet

A `<CodeSnippet />` is used to improve readability of embedded code samples with syntax highlighting and automatic line numbering.

## Usage

```tsx
import { CodeSnippet } from "@easypost/easy-ui/CodeSnippet";
```

### Syntax colors and themes

Syntax colors follow the nearest `Provider` or `ThemeProvider`, including light,
dark, system, and inverted color schemes. JSON values, strings, keywords,
comments, and line numbers retain distinct syntax roles without consumer CSS
overrides.

<Canvas of={CodeSnippetStories.SyntaxColors} />

Switching the active theme updates mounted snippets, including a nested inverted
provider.
