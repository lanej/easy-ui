# CompactTimeSeries

A native SVG time series with sparse axes, optional observation markers and a labeled reference. Import from `@easypost/easy-ui/CompactTimeSeries`. No ECharts dependency.

<Canvas of={Stories.Default} />
<Canvas of={Stories.Comparison} />

Supply one to three series with unique IDs and strictly increasing timestamps in milliseconds. Elapsed spacing is preserved. `null` and non-finite values create gaps; isolated observations remain visible. Zero is an observation. `domain` defines the vertical scale; `timeDomain` can define a shared horizontal scale. Values and references must fit the displayed domains. Invalid domains, ordering, or out-of-range observations suppress the plot with `invalidDataLabel`; exact supplied values remain in the data disclosure.

Provide explicit time-zone/period/coverage context. `formatTime` and `formatValue` own exact timestamps and values in the keyboard-operable disclosure; use optional `formatAxisTime` and `formatAxisValue` for short axis labels. When omitted, axes retain the original formatters. A sole inferred timestamp centers both its tick and its observations; an explicit wider time domain retains the true time position. `typography` controls title, description, axis label, legend, disclosure control and detail sizes independently.

Labels and line dashes distinguish series beyond color. Markers can be `none`, `all`, `endpoints` of each segment, or global `extrema` (first observation of tied extrema).

Linear interpolation is the default. `step-after` retains the previous value until the next observation, for effective-dated prices and policies. It does not fill missing intervals. No implicit smoothing, animation, aggregation, or statistical calculation.

<Canvas of={Stories.NoData} />

Use the same value and time domains for panels intended for comparison. The component owns no brushing, zoom, or shared selection machinery. Use `Chart` for more series, dense inspection, uncertainty bands, and analytical interactions. Resize observers are released on unmount; SSR starts with deterministic geometry before measuring the container.
