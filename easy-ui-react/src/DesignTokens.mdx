# Design Tokens

Browse the values behind Easy UI's styles. Samples use the generated CSS variables. Filter by group, name, value, or CSS variable.

  <TokenBrowser />
</div>

## Usage

Reference tokens through the SCSS `design-token()` helper:

```scss
@use "@easypost/easy-ui/styles/token-helpers" as *;

.button {
  color: design-token("color.primary.500");
  padding: design-token("space.2");
  border-radius: design-token("shape.border_radius.md");
}
```

Use theme-aware names such as `color.primary.500` or `color.neutral.800` so components follow the active theme. Base colors such as `color.blue.500` stay fixed. See <a href="./?path=/docs/foundations-colors--docs" target="_top">Colors</a> for the palette and <a href="./?path=/docs/foundations-typography--docs" target="_top">Typography</a> for composed text styles.

Names and values remain selectable for copying. Theme tokens show light and dark values together. Dimensions render at their actual size; breakpoint bars use a shared relative scale.

Token values come from the generated JavaScript package. The CSS build converts dimension tokens from pixels to rems (or ems for breakpoints), using 16 px as its baseline. Samples apply those CSS variables, so they also respect the browser's root font size. Font weights, families, and responsive typography mappings are shown with their declared values; the icon font requires its own font asset.
