# DurationDistribution

Compare an ongoing elapsed duration with a caller-supplied reference of completed durations. This molecule renders a native SVG/CSS plot and composes with the `HealthAssessment` organism; it does not require a chart engine. It reuses the visualization scale and value-state utilities. `RangePlot` remains useful for named ranges, but cannot express this shared histogram/CDF overlay.

<Canvas of={Stories.Default} />

```tsx
import {
  DurationDistribution,
  DurationQuantileMetrics,
} from "@easypost/easy-ui/DurationDistribution";

<DurationDistribution
  value={6}
  unit="hours"
  domain={[0, 30]}
  quantiles={[
    { fraction: 0.5, value: 9 },
    { fraction: 0.9, value: 18 },
  ]}
  bins={completedDurationBins}
  cumulative={completedDurationCDF}
  healthRegions={applicationPolicy}
  currentAssessment="healthy"
/>;
```

## Supply the reference rather than infer it

| Source          | Contract                                                                                | Rendering                                                                        |
| --------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `quantiles`     | Fractions in [0,1], strictly increasing; durations nonnegative and nondecreasing        | Fixed-size percentile landmarks; tied durations are valid                        |
| `bins`          | Ordered, disjoint half-open [from,to) intervals with integer nonnegative counts         | Count histogram; gaps retain their positions                                     |
| `cumulative`    | At least two points ordered by nonnegative duration and nondecreasing fraction in [0,1] | Supplied cumulative percentage curve; repeated durations support empirical jumps |
| `healthRegions` | Ordered disjoint [from,to) policy intervals; the final upper bound may be Infinity      | Semantic bands and landmark colors, independent of distribution                  |

Quantiles alone render a horizontal reference bar with percentile dots and the current-value marker. Supplied health bands color the bar; without bands it remains neutral. They do not establish a density, histogram, or cumulative curve. No endpoints, quartiles, counts, cohorts, sample sizes, or health classifications are inferred. Each supplied source is validated independently; an invalid source is identified and omitted while other valid sources remain usable. Reference arrays may be absent, null, or empty. An all-zero histogram explicitly reports no completed observations. Sample count is optional, separately supplied metadata; the application owns whether it covers the whole cohort or only the displayed window.

Set `showPercentileLabels` to show each percentile and its duration beneath the quantiles-only bar, for example **P50 9 h** and **P90 18 h**. Labels are off by default; the same control works for bar and curve presentations. Labels retain the percentile's semantic color and align with its dot. On narrow references each pair stacks.

`interpolation="linear"` joins supplied cumulative points with straight segments; this is an interpolated historical reference, not a completion forecast. Use `"step"` for a right-continuous empirical CDF. There is no extrapolation beyond the supplied cumulative coverage. Quantile points use their supplied fractions when a curve is visible and sit on the baseline otherwise. The elapsed vertical line remains distinct; it receives a curve dot only where a supplied cumulative value can be interpolated. Histogram height represents counts, while curve height represents cumulative fraction. They share a duration x-axis and independent vertical scales.

Use the same cohort, unit, and observation window for sources meant to be compared. The component does not aggregate raw observations, reconcile independently computed statistics, choose a kernel-density bandwidth, or convert units. Default number formatting preserves the supplied numeric value with `String`; optional formatters are caller-owned. `formatValue` formats the number only, followed by the explicit `unit`.

## Keep assessment and duration separate

The current marker uses `currentAssessment`, never an assessment derived from its percentile. Historical landmarks use the supplied health interval containing their duration. Hiding bands preserves that color policy. Without policy, landmarks are neutral. Overlapping, reversed, or invalid policy intervals are explicitly identified and their historical marks become neutral. Values below the median do not automatically mean healthy. Ongoing elapsed duration is labeled separately from the completed-duration reference.

The axis labels both ends of supplied health ranges, including gaps, and shows shared boundaries once. The current assessment is supplied independently of those ranges; its text equivalent is included in the plot description, marker tooltip, and optional exact-data disclosure. Localize it with `labels.currentAssessment`, `labels.healthy`, `labels.degraded`, and `labels.unhealthy`. Unavailable or invalid elapsed values suppress that assessment text.

## Optional context and exact data

Bands, band names, percentile points, percentile labels/guides, right count axis, and visible sample count are independently optional. No percentage y-axis is shown. `description` and `cohort` provide visible application context when supplied. The sample count is included in the accessible description when supplied, and displayed only with `showSampleCount`. Synthetic data in these examples is fabricated demonstration data, not required product copy.

`showDataTable` exposes exact supplied observations through a native keyboard-accessible disclosure. It is independent of the histogram, which never expands into a separate graph. Cumulative points, quantiles, and histogram bins retain exact values in this view even when clipped by the viewport. Keep labeled quantiles sparse on narrow plots; points plus `DurationQuantileMetrics` provide a more compact comparison for dense references.

## Binned or smooth, full plot or compact concentration

Choose the representation independently from the cumulative-percentile curve:

| Option                                     | Behavior                                                            |
| ------------------------------------------ | ------------------------------------------------------------------- |
| `distributionStyle="binned"`               | Histogram bars, or stepped color intensity in the compact bar       |
| `distributionStyle="smooth"`               | A smooth density curve, or blended concentration in the compact bar |
| `distributionPresentation="plot"`          | Full-height distribution; the default                               |
| `distributionPresentation="concentration"` | An 8px reference bar with gentle relative-density intensity         |

Use `visualization="histogram"` to show the distribution without its cumulative curve; `"both"` or `"auto"` can overlay the separately supplied cumulative reference. Quantiles-only data still produces landmarks on a neutral or health-colored bar: it never invents a density.

Smooth mode is explicitly a smoothed histogram, not a kernel density estimate or a completion forecast. It uses bounded cubic interpolation between bin-center densities (`count / interval width`), retaining the outer half-bin's density within each supplied interval. It neither extends beyond supplied coverage nor bridges missing intervals. The compact binned bar also uses count per duration unit so unequal widths remain comparable. Intensity is relative to the peak of the full supplied reference, capped for a soft appearance in both themes. Health hues change at their supplied thresholds; concentration blends within them. The count axis applies only to binned full-height bars. Exact original bin counts remain available through `showDataTable` in every form.

## Missing, invalid, and outside values

`domain` is a finite increasing nonnegative viewport. Invalid scales suppress graphical geometry. Null elapsed values are unavailable; negative and nonfinite durations are invalid. Valid reference data remains visible when elapsed duration is missing. Outside elapsed and quantile values retain their exact value and state, with marks omitted by default. `overflow="clamp"` explicitly puts their marks at a boundary without changing the exact text. Curves and bins are clipped to the viewport; an explicit message identifies references extending outside it. Loading suppresses previous data, assessment, and metadata.

## Compose with observation presentations

`DurationDistribution` owns the reference comparison: the shared scale, histogram, cumulative curve, reference bands, and percentile marks. `HealthAssessment` owns the overall assessment presentation and responsive visibility. Use the molecule independently for graph-only views or compose it into the organism; both paths use the same rendering implementation.

`DurationQuantileMetrics` is an independently usable companion that shares unit formatting and supplied health policy. Put it in `HealthAssessment.observationDetails` and the graph in `reference`. HealthAssessment's compact, detailed, default, wide, and responsive forms control layout and progressive visibility; DurationDistribution's options control the graph's own content. `stretch` fills the reference column with a minimum plot height of 100px.
