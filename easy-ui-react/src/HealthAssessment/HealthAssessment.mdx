# HealthAssessment

Keep an observation's name, value, assessment, and observation time together, with a reference alongside them. Use this molecule wherever an individual observation needs that context.

<Canvas of={Stories.Default} />

```tsx
<HealthAssessment
  label="Elapsed duration"
  health={{ assessment: "healthy", label: "As expected" }}
  observation={{ value: 6, unit: "hours" }}
  reference={
    <DurationReferenceExample
      value={6}
      currentAssessment="healthy"
      regions={assessmentRanges}
      section="primary"
    />
  }
  freshness={{
    state: "fresh",
    observedAt: "2026-01-15T12:00:00Z",
    formatObservedAt: (value) =>
      new Intl.DateTimeFormat("en-US", {
        dateStyle: "medium",
        timeStyle: "short",
        timeZone: "UTC",
      }).format(new Date(value)),
  }}
/>
```

## Presentation forms

`variant` controls the amount and arrangement of supplied content, independently of `size` and the optional chart features.

| Form         | Content                                                       | Maximum width |
| ------------ | ------------------------------------------------------------- | ------------- |
| `compact`    | Assessment pill and headline value                            | 320px         |
| `detailed`   | Reference graph only                                          | 640px         |
| `default`    | Headline, optional percentile metrics, and tighter graph      | 640px         |
| `wide`       | Full observation context and a wider graph                    | 960px         |
| `responsive` | Progressively reveals supplied content as its container grows | 960px         |

<Canvas of={Stories.PresentationForms} />

The responsive form always keeps the pill and value. At 320px it adds supplied percentile metrics, label, and freshness; at 560px it adds the graph alongside them; at 840px it includes any supplied reference details. Hidden supplemental metrics and graphs are also excluded from the accessibility tree; the observation label remains available to screen readers. These are container widths, so a narrow dashboard card remains compact even on a large screen. The application still decides whether to supply each optional slot or chart feature. No metrics or reference are synthesized when absent.

## Keep value and assessment together

The value carries the most visual weight. Standard assessments with a reference use the larger headline duration; compact assessments retain their smaller scale. The small pill above the headline states the supplied assessment without relying on color. A freshness status dot sits beside the supporting timestamp beneath it; the timestamp prefix is optional. At wider widths both columns share the same content height. The observation label anchors the top, the pill sits above the headline in the middle, and freshness anchors the bottom. The observation spans optional `referenceDetails` content as well, so its height follows the complete reference column. Narrow layouts stack content in reading order. `referenceLayout="compact"` keeps a horizontal comparison when the container is at least 360px wide, and stacks below that width to keep labels readable.

The application supplies each assessment, reference, and freshness state. The molecule does not compare durations, infer thresholds, or classify observations. These synthetic examples use a cumulative curve on a 0–30 hour scale. The curve keeps its cumulative percentage geometry without a visible vertical axis. The curve interpolates between cumulative counts from the synthetic observations; it is a historical reference, not a completion forecast. An elapsed marker matches the supplied assessment color and uses a contrasting outline to show the current observation. Percentiles are optional. Each percentile uses the assessment hue of the supplied range it falls in, consistently across points, guides, labels, and optional submetrics. In this example P50 at 9h is expected (green), while P90 at 18h needs attention (amber). Those colors describe historical landmarks relative to the application’s policy; percentile rank itself never determines health. Missing policy uses neutral marks. Hiding background bands does not remove the supplied policy. Dark themes use brighter tones for contrast. Enable the story-only `showPercentileMetrics` control to place a compact color key and duration submetrics immediately beside the headline, before the graphical comparison. Reference points and the current-value marker use equal, fixed-size dots; the vertical line distinguishes the current observation. This content is supplied through the optional `observationDetails` slot; callers can supply their own submetrics. The legend is omitted when percentile marks or the reference are hidden. The default shows P50 and P90 as points without guide lines or labels; hover identifies each duration. Enable `showPercentileLabels` in the story controls for labeled guides, or disable `showPercentiles` to remove all percentile marks. In labeled mode, P50 (9 hours) and P90 (18 hours) pair each percentile with its duration directly beneath the tick. The pairs share a line when space permits and stack in very narrow references. These landmarks describe completed durations independently of the ongoing elapsed duration; they do not establish health or predict completion.

The optional histogram overlays the curve on the same duration axis, with no disclosure or height expansion. Bars split color exactly where they cross supplied health thresholds. Their height represents counts per interval; the curve represents cumulative percentage. These are independent vertical scales. `showCountAxis` optionally exposes the histogram’s right count scale. The sample caption is optional through `showSampleCount` and hidden by default. “Synthetic” means these Storybook observations are fabricated; it is demo metadata, not required product copy.

Labeled background regions show illustrative assessment ranges supplied by the application: **As expected** below 10 hours, **Needs attention** from 10 to less than 20 hours, and **Outside expectations** at 20 hours or more. These boundaries are independent of the distribution's percentiles. The last range continues beyond the displayed 30-hour scale. The story's application policy supplies both the pill and the ranges, keeping them consistent when the observation changes.

## Optional reference context

Choose `referenceVisualization="cumulative"`, `"histogram"`, `"both"`, or `"none"` in the story-only example. The cumulative curve is the default. `showReferenceDistribution` independently controls its histogram overlay. Both mode overlays histogram and curve directly; histogram mode shows just the histogram. `showHealthBands` independently controls background assessment ranges. None mode removes the reference column.

In application code, omit the optional `reference` prop for value, assessment, and freshness alone. Supply only the reference content that the application needs; the molecule never creates graphics automatically.

## Compare reference options

Health-band names and ranges are optional independently of the colored bands. By default, the supplied band thresholds share the duration-axis row; labeled percentiles place thresholds on a separate row to avoid overlap. Enable `showHealthBandLabels` in the story controls to restore the named header. The assessment pill continues to state health in text.

Each example uses the same observation and width. Column heights follow optional labels and metadata. Switching the histogram overlay on or off preserves the same column height. Omitting the reference returns to a compact observation.

## Preserve distinct data states

- **Loading:** suppress the previous value, assessment, and reference while fetching.
- **Unavailable:** a supplied observation with a null, negative, or nonfinite value cannot support a health assessment.
- **Unassessed:** a valid value can exist without a health assessment. Never infer one from the duration.
- **Stale:** keep the observed value and supplied assessment, accompanied by its observation time and stale label. The application can suppress the assessment with `health.availability="unavailable"` if its policy requires it.
- **Zero:** display zero as a real observation.

<Canvas of={Stories.DataStates} />

Omit `observation` entirely for an assessment that does not measure duration. `reference` remains an optional composition slot. `DurationReferenceExample` is a story-only example; its synthetic histogram and percentiles come from the same completed observations. Missing elapsed values omit the current marker while retaining the reference. Missing or unassessed health omits the colored ranges and uses neutral percentile marks and bars. The reusable distribution component is tracked separately in [#16](https://github.com/lanej/easy-ui/issues/16).

## Fit the surrounding information

Use `label` to name a standalone observation. In a table or another labeled context, omit it when the surrounding heading already identifies the measurement. `size="sm"` reduces emphasis and spacing for dense layouts.

<Canvas of={Stories.CompactTable} />

Localize labels, value formatting, and timestamps through the individual atom props. Supply the timezone as part of the formatted timestamp when it matters. The visible `label` also names the containing group for assistive technology; when it is omitted, use `accessibilityLabel`. Content wraps within the available width, including at enlarged text sizes.
