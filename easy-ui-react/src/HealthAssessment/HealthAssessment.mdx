# HealthAssessment

Keep an observation's name, value, assessment, and observation time together, with a reference alongside them. Use this molecule wherever an individual observation needs that context.

<Canvas of={Stories.Default} />

```tsx
<HealthAssessment
  label="Elapsed duration"
  health={{ assessment: "healthy", label: "As expected" }}
  observation={{ value: 6, unit: "hours" }}
  reference={<DurationReferenceExample value={6} regions={assessmentRanges} />}
  freshness={{
    state: "fresh",
    observedAt: "2026-01-15T12:00:00Z",
    formatObservedAt: (value) =>
      new Intl.DateTimeFormat("en-US", {
        dateStyle: "medium",
        timeStyle: "short",
        timeZone: "UTC",
      }).format(new Date(value)),
  }}
/>
```

## Keep value and assessment together

The value carries the most visual weight. Standard assessments with a reference use the larger headline duration; compact assessments retain their smaller scale. Its adjacent small pill states the supplied assessment without relying on color. A freshness status dot sits beside the supporting timestamp beneath it; the timestamp prefix is optional. At wider widths the reference sits beside this information; narrow and compact layouts stack it below.

The application supplies each assessment, reference, and freshness state. The molecule does not compare durations, infer thresholds, or classify observations. These synthetic examples use a cumulative curve on a 0–30 hour scale. The vertical axis shows percentage completed. The curve interpolates between cumulative counts from the synthetic observations; it is a historical reference, not a completion forecast. An elapsed marker matches the supplied assessment color and uses a contrasting outline to show the current observation. P50 (9 hours) and P90 (18 hours) pair each percentile with its duration directly beneath the tick. The pairs share a line when space permits and stack in very narrow references. These landmarks describe completed durations independently of the ongoing elapsed duration; they do not establish health or predict completion.

Expand **Reference distribution** to inspect the completed-duration histogram. The disclosure uses native keyboard behavior, and its histogram uses the same scale and percentile positions as the curve.

Labeled background regions show illustrative assessment ranges supplied by the application: **As expected** below 10 hours, **Needs attention** from 10 to less than 20 hours, and **Outside expectations** at 20 hours or more. These boundaries are independent of the distribution's percentiles. The last range continues beyond the displayed 30-hour scale. The story's application policy supplies both the pill and the ranges, keeping them consistent when the observation changes.

## Optional reference context

Choose `referenceVisualization="cumulative"`, `"histogram"`, `"both"`, or `"none"` in the story-only example. The cumulative curve is the default. `showReferenceDistribution` independently controls its optional histogram disclosure. Both mode shows aligned charts directly; histogram mode shows just the histogram. `showHealthBands` independently controls background assessment ranges. None mode removes the reference column.

In application code, omit the optional `reference` prop for value, assessment, and freshness alone. Supply only the reference content that the application needs; the molecule never creates graphics automatically.

## Preserve distinct data states

- **Loading:** suppress the previous value, assessment, and reference while fetching.
- **Unavailable:** a supplied observation with a null, negative, or nonfinite value cannot support a health assessment.
- **Unassessed:** a valid value can exist without a health assessment. Never infer one from the duration.
- **Stale:** keep the observed value and supplied assessment, accompanied by its observation time and stale label. The application can suppress the assessment with `health.availability="unavailable"` if its policy requires it.
- **Zero:** display zero as a real observation.

<Canvas of={Stories.DataStates} />

Omit `observation` entirely for an assessment that does not measure duration. `reference` remains an optional composition slot. `DurationReferenceExample` is a story-only example; its synthetic histogram and percentiles come from the same completed observations. Missing elapsed values omit the current marker while retaining the reference. Missing or unassessed health omits the colored ranges. The reusable distribution component is tracked separately in [#16](https://github.com/lanej/easy-ui/issues/16).

## Fit the surrounding information

Use `label` to name a standalone observation. In a table or another labeled context, omit it when the surrounding heading already identifies the measurement. `size="sm"` reduces emphasis and spacing for dense layouts.

<Canvas of={Stories.CompactTable} />

Localize labels, value formatting, and timestamps through the individual atom props. Supply the timezone as part of the formatted timestamp when it matters. The visible `label` also names the containing group for assistive technology; when it is omitted, use `accessibilityLabel`. Content wraps within the available width, including at enlarged text sizes.
