# HistogramChart

Show supplied counts for equal-width buckets. It does not bin raw observations or infer a density.

## Usage

```tsx
import { HistogramChart } from "@easypost/easy-ui/HistogramChart";
```

## Examples

Import `{ HistogramChart }` from `@easypost/easy-ui/HistogramChart`. Install the optional `echarts@^6.1.0` peer when using analytical charts.

Pass native ECharts records through `series`; the component supplies the series `type`. `option` configures native axes, grids, legends, annotations, datasets, media overrides, and zoom. There is no second axis or styling grammar. Caller values override this component's defaults. Keep stable series and datum IDs for selection and ordinary refreshes.

This categorical histogram assumes equal-width buckets. For supplied intervals of unequal widths and native density rendering, use `DurationDistribution` with its `bins` API.

Use `dataTable` from the same records for exact values and keyboard drill-down. `onSelect`, `onRowSelect`, controlled legend/zoom, statuses, typography, and `variant="bare"` use the shared [Chart contract](?path=/docs/components-chart--docs). Applications own units, aggregation, interpretation, and provenance.
