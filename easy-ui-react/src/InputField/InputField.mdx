# InputField

The shared input primitive used by `TextField` and `Textarea`. It owns labels,
validation feedback, input adornments, and password visibility. Use `TextField`
or `Textarea` for their more focused application APIs.

## Usage

```tsx
import { InputField } from "@easypost/easy-ui/InputField";

<InputField label="Shipment reference" placeholder="Enter a reference" />;
```
