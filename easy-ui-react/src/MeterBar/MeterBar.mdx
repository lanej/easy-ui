# MeterBar

Display a bounded measurement or compare several measurements on a shared scale.
MeterBar adds no card, title, assessment, or alert. Labels and exact values are
included when using the comparison API.

## Usage

All comparison rows use the same units and the same explicit maximum. Color
identifies a series; it does not imply that a measurement is good, bad, or risky.

<Canvas of={MeterBarStories.Comparison} />

```tsx
import { MeterBar } from "@easypost/easy-ui/MeterBar";

<MeterBar
  data={[
    { id: "sac", label: "Sacramento", value: 4.2, color: "primary" },
    { id: "oak", label: "Oakland", value: 7.8, color: "secondary" },
    { id: "sjc", label: "San Jose", value: 3.1, color: "tertiary" },
  ]}
  max={12}
  thickness="lg"
  formatValue={(hours) => `${hours.toFixed(1)} h`}
  accessibilityLabel="Average dwell time by facility, 0 to 12 hours"
/>
```

Keep `max` fixed across comparable lists. Removing a row does not rescale the
remaining measurements. Input order is preserved. Do not combine hours, counts,
and percentages on one scale.

## Props

<Controls of={MeterBarStories.Comparison} />

Use `value` for a visual-only single bar or `data` for labeled comparison rows.
Both modes require a finite `max` greater than zero.

`color` accepts `primary`, `secondary`, and `tertiary` from the theme palette.
Comparisons default to `primary`; an unstyled single-value bar remains neutral.
Set one group color or give individual rows their own colors.

`tone` remains available for caller-supplied `neutral`, `success`, `warning`, or
`danger` meaning. It only selects a fill color: MeterBar never calculates an
assessment, applies thresholds, or renders alert UI.

Row styling overrides group styling. A row's `tone` takes precedence over its
`color`; otherwise its `color` takes precedence over a group tone. Without row
styling, the group tone takes precedence over the group color. Explicit
`tone="neutral"` is neutral, not the default comparison blue.

`formatValue` controls visible and accessible value text without changing
geometry. `accessibilityLabel` names the comparison group without adding a
visible heading. `unavailableLabel` customizes missing-value text.

### Zero and missing values

Zero is a measured value. Missing, nonfinite, negative, and out-of-range values
are unavailable, not zero. Invalid single values draw nothing; invalid comparison
rows retain their label and `unavailableLabel`, without a misleading meter.

<Canvas of={MeterBarStories.ComparisonStates} />

### Accessibility

Comparisons expose one accessible meter per valid row. Labels, units, and numeric
values remain available independently of color. RTL, localized numbers,
large-text reflow, forced colors, and composed-component states are covered by
regression fixtures rather than additional usage examples in this showcase.
