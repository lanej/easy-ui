# MeterBar

A visual-only atom for a bounded value: one track and one proportional fill. Import from `@easypost/easy-ui/MeterBar`. No card, chart engine, labels, percentage formatting, assessments, or loading policy.

## Usage

```tsx
import { MeterBar } from "@easypost/easy-ui/MeterBar";
```

## Examples

### Compose meaning, share rendering

`ProportionBar` and `RiskScore` both compose this atom. A proportion owns its percentage and population counts; a risk score owns its score/maximum and supplied assessment. A score of 72 out of 100 must not become a claim of 72% probability.

The atom is always `aria-hidden` and adds no meter role or keyboard stop. The owning molecule exposes one accessible meter with its exact value, range, name, and value description. When using the atom directly, supply equivalent accessible information in the surrounding composition; do not use the bar as the sole representation of data.

### Geometry and presentation

`value` must be finite and within `[0, max]`; `max` must be finite and positive. Invalid input draws nothing rather than clamping it to a believable score. Zero draws an empty track, and a value equal to its maximum fills the track. Geometry uses the unrounded `value / max`, without an invented minimum fill. The caller handles unavailable, invalid, empty-population, and loading states before rendering this atom.

Tone is supplied, never inferred from magnitude. `thickness` is `sm` (4px), `md` (8px, default), or `lg` (12px). The shared design-token colors and high-contrast rendering apply to both molecules. Fill starts at the inherited inline start, including RTL. No motion or completion behavior is added.
