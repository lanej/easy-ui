# SelectorErrorTooltip

A focusable error icon with a tooltip. Checkbox and other selection controls use
this helper to display validation details. It supplies an accessible “Error”
label and shares the behavior of `Tooltip`.

## Usage

```tsx
import { SelectorErrorTooltip } from "@easypost/easy-ui/SelectorErrorTooltip";

<SelectorErrorTooltip
  content="Select an option before continuing."
  isImmediate
/>;
```

<Canvas of={Stories.Default} />

## Props

<ArgTypes of={Stories} />

Accepts the `Tooltip` props except `children`; the trigger is the error icon.
