# Textarea

The `<Textarea />` component allows users to input text on multiple lines.

## Usage

```tsx
import { Textarea } from "@easypost/easy-ui/Textarea";
```

<Canvas of={TextareaStories.Standard} />

## Examples

### Standard

Simple `<Textarea />` with `label`, `placeholder`, and `helperText`.

### Custom row height

To specify the visible height of a text area in lines, use the `rows` property.

<Canvas of={TextareaStories.CustomRowHeight} />

### Large Textarea

Set `size="lg"` for a large `<Textarea />`.

<Canvas of={TextareaStories.LargeTextarea} />

### Label with emphasis

Use `isLabelEmphasized=true` to display a label with emphasis.

<Canvas of={TextareaStories.LabelWithEmphasis} />

### Error

When `validationState` is set to `invalid`, the `<Textarea />` displays with error styles.

<Canvas of={TextareaStories.Error} />

### Visually hidden label

A `label` can be visually hidden by omitted the `label` property, but to main accessibility, provide an `aria-label`.
