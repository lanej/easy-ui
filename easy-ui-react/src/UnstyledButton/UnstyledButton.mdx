# UnstyledButton

The button behavior primitive used by `Button` and other controls. It supports
pointer and keyboard activation, disabled state, and links without prescribing
visual styling. Use `Button` when the standard appearance fits; supply a class
and visible focus styling when building a custom control.

## Usage

```tsx
import { UnstyledButton } from "@easypost/easy-ui/UnstyledButton";

<UnstyledButton onPress={() => console.log("Activated")}>
  Activate button
</UnstyledButton>;
```
