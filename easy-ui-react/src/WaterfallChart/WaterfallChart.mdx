# WaterfallChart

Show signed changes and their running balance. Interval geometry handles negative balances and crossings of zero; the final bar spans zero to the supplied ledger total.

## Usage

```tsx
import { WaterfallChart } from "@easypost/easy-ui/WaterfallChart";
```

## Examples

Import `{ WaterfallChart }` from `@easypost/easy-ui/WaterfallChart` with the optional `echarts@^6.1.0` peer installed.

`steps` contain stable `id`, `label`, and a finite signed `change`. `initialValue` defaults to zero. Each bar runs from the previous balance to the next, and `totalLabel` names the final zero-to-balance bar. Set `showValues` to show signed direct labels; `formatValue` supplies their units. `increaseItemStyle`, `decreaseItemStyle`, and `totalItemStyle` accept native style overrides for application meanings. Default colors distinguish direction without assigning good/bad meaning. Supply axis units through `option` and formatted exact data when needed.

`option` configures native axes, tooltips, grids, media overrides, and zoom; the component owns its series geometry. A default exact-data table is generated from the same records. Supply `dataTable` to format units or enrich provenance; set `showDataTable={false}` when the application provides another exact-value view.

Selection, keyboard data access, controlled zoom, rendering states, themes, typography, and `variant="bare"` follow the shared [Chart contract](?path=/docs/components-chart--docs).

`option.color` supplies the first three automatic colors for increases, decreases,
and the total. Explicit item styles take precedence. These slots remain stable
when a direction has no steps, including in native media and timeline options.
The native selection identifies the role through `seriesId`; the selected datum
retains the original step `id`, label, and signed value. Its `dataIndex` is within
that role's series rather than the full ledger.
